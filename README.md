## 👋 Hola Soy Matias Ignacio Pastorelli 👋

## 👨‍💻 Sobre mi 👨‍💻

👨‍💻 Desarrollador Backend con 4 años de experiencia creando APIs y microservicios que funcionan bien, escalan y se mantienen. Trabajo con Node.js (Express, NestJS) y Laravel, usando Docker, Kubernetes/ECS y pipelines de CI/CD (Jenkins, GitLab CI, GitHub Actions).

💡 Manejo JavaScript, TypeScript, PHP 8, PostgreSQL, MongoDB, Redis, y algo de DynamoDB. He integrado Kafka y RabbitMQ, y participé en proyectos con arquitecturas event-driven.

🧪 Aplico buenas prácticas como TDD/BDD (Jest), con foco en la calidad del código (cobertura +85 %, análisis en SonarQube, escaneos OWASP).

☁️ En el cloud (AWS) he optimizado recursos con Lambda, API Gateway, RDS, S3, logrando mejoras en costos y disponibilidad.

🔄 Participé en migración de un monolito a microservicios (despliegues de 40 min a 7 min). Además, he mentorado a devs junior, apoyando en code reviews y pair programming.

🤝 Me destaco por la comunicación clara, pensamiento crítico y ganas de seguir aprendiendo. Busco equipos con cultura técnica sólida, donde pueda crecer en serverless, seguridad y observabilidad.
